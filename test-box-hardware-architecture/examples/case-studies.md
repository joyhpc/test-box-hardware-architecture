# 匿名证据角色与可复用问题

这些条目是历史审查的**泛化索引**。项目身份、文件名、路径、hash、日期和非公开设计细节均不发布；不是可独立复核的实物 case，也不证明某产品有缺陷或修复成功。原始事实与版本关系只应保存在项目授权的私有证据库。公开条目仅支持方法来源与适用边界，见 [manifest](source-manifest.json)。新的数值示例全部另行标为 SYNTHETIC。

| Source role | 泛化观察 | Pattern / scope | 反例与验证 |
|---|---|---|---|
| SRC-P1-REVIEW：跨板接口与供电审查 | 历史报告与后续资料未必属于同一实物配置；局部掉电不能从正常工作外推 | 版本分层、partial-power interface contract | 同名接口或相同端点状态不足以证明兼容；按受控 HW/Assembly/FW 基线验证供电组合及转换窗 |
| SRC-P2-SPEC：视频采集需求草稿 | 草稿表达的目标不能当持续链路实测能力 | 需求→并发配置→逐跳容量→端到端测试 | 单跳峰值通过可能仍在 Host 落盘失败；以独立 SYNTHETIC worked example 演示，而非公布原项目指标 |
| SRC-P3-CONTROL：FPGA 适配控制审查 | IO 电压兼容和 owner 在 pin plan 前需要显式关闭 | 电压域/Bank 预算、默认态、所有权 | GPIO 总数足够不代表 Bank 可放；核具体 family/封装、专用脚、供电和切换行为 |
| SRC-P4-DEBUG：数字接口分析 | 系统启动、模块 ready 与协议事务不是同一个状态机 | 分层 lifecycle、首个可观测分叉 | 数字解码不能证明眼图/共模，相关性不能直接给根因；同步电源/clock/reset/协议观测并做隔离实验 |

这些是有限经验提示，不能提升为任何架构都必须使用某电压、通道数或器件的规则。每次泛化应保留适用范围、替代解释和可证伪测试。公开评测使用的情景已泛化；旧记录的隐私编辑另有标注，不宣称逐字原始记录。
