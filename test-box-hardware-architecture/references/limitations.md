# Remaining Limitations

- 行为评测由作者在本次会话执行和自评，非独立盲测或统计成功率；尚未在新产品完整项目中验证。T6输入为文本框图，未测试扫描图像识别。
- 本次未连接硬件、上电、故障注入、运行固件/FPGA、做SI/PI/EMC仿真或整机试验；所有真实case只读资料、历史报告和已有解码结果。根因假设与已观测现象严格分开。
- 未取得所有受控标准、准确器件资料/errata、PCB、RTL、线缆/拓扑和环境等级；Skill不会给通用电气保证值或认证。具体设计必须补充这些证据。
- 公开case只有匿名角色与一般机制，未公开原始资料，不能提供独立原件复核。历史SELF记录做过已披露的隐私泛化；不能用于重现原项目。
- Sizing是声明参数上的算术模型。示例IP区间为虚构教学占位；没有综合/布局/PVT或真实持续吞吐依据。GT/Bank数量与内存块数满足不代表实际器件映射、speed grade或热设计通过。
- budget v2不模拟格式变换、multicast、虚拟通道调度或任意服务曲线；resource采用固定独立队列、声明的可用块容量与统一memory/logic利用率。分支可建模，但必须显式给每条端到端路径。
- 离线工具依赖人工声明的模型，不理解原理图连接、模拟行为或自然语言契约真假；STRUCTURALLY_COMPLETE不是工程通过。差分不自动识别所有不变风险与瞬态，依赖图只对声明边有效。
- 模块化评分与复用收益是决策辅助，需项目成本、数量与测试证据；不承诺任意器件替换不改Core。

后续优先：固定新项目baseline后完成端到端实例；取得准确partial-power/receiver保证值；有授权时做独立前向评测；保留实测闭环与新反例，逐项缩小以上限制。
